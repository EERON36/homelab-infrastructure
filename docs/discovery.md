# Repeatable local discovery

## Scope

The script supports PowerShell 7 on Windows and an existing private IPv4 interface with a /24 subnet. It sends ARP requests for addresses 1 through 254 on that interface, excluding the source address. It also reads local Hyper-V inventory and Tailscale reported status when available. No additional software is installed.

ARP requests discover local address neighbours. They do not enumerate remote VLANs or the guests behind remote hypervisors. The scan can take several minutes because Windows waits for unanswered requests. Offline status in Hyper-V is authoritative for that local VM at collection time; a missing ARP response is not proof that a device is off.

## Run

Use `ipconfig` to find the IPv4 address of the intended home Ethernet or Wi-Fi interface. Review the script, then run this command with that address in place of the placeholder:

```powershell
./scripts/Discover-LocalLab.ps1 -SourceIPv4 '<your-local-IPv4-address>'
```

If Windows denies inventory access, run from an authorized PowerShell session with the needed Hyper-V permissions. The script records unavailable optional inventories in `gaps`. It does not elevate itself or change firewall, VM, router, or Tailscale settings.

## Results and privacy

Timestamped JSON files are written to `local-discovery/`, which Git ignores. These files contain private names, IP addresses, hardware addresses, and virtual switch details. Keep them local. Tailscale output is reduced to inventory fields before saving; account profiles and node keys are not retained.

The initial `aliases.json` in that same local folder links aliases used in the committed documentation to actual records. It belongs to the initial snapshot and is not regenerated by the discovery script. Future snapshots require alias reconciliation before updating the sanitized inventory.

Before committing changes, check the staged diff and confirm `git check-ignore local-discovery/example.json` succeeds. An ignore rule is not a secret scanner and does not remove files already tracked.

## Initial validation

The script completed a real LAN discovery run on 17 October 2026 and saved the local JSON snapshot. Hyper-V and Tailscale collection both succeeded. VM states were initially serialized as numeric enum values; the reusable script now saves readable state names. The updated script passed PowerShell parsing; the full network scan was not repeated for this serialization-only change. The sanitized JSON was parsed, and Git ignore coverage and all files selected for GitHub were checked. This was not a remote hypervisor inventory, complete network census, service audit, or end-to-end infrastructure acceptance test.
